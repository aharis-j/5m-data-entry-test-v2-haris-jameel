# Question 5 — Operating Systems, Terminals, and Shells

**Format:** Short Answer

---

> Answer in your own words, 1-3 sentences each. Writing it yourself is the point.


**(a)** What is a **kernel**, in plain language? (One or two sentences. No textbook definition copied in; explain it as you understand it.)

**Answer:**
It is a programme which can be likened to the command centre of an operating system. It interfaces important hardware and software processes to keep the computer running smoothly. A computer cannot function properly if there are problems with the kernel.

---

**(b)** A classmate says:

> "I installed WSL, so now I have two completely separate operating systems, Windows and Linux, running side by side, each totally independent."

Is this accurate? Briefly explain why or why not.

**Answer:**
This is not accurate. Running Windows and Linux indepedently on the same machine would require a Linux installation within a proper virtual machine on the Windows OS, or a separate Linux installation on one of the OS disks. Instead, WSL is running Linux shell commands on Windows by means of a translation layer (WSL) or via a simplified virtualisation of the Linux kernel (WSL 2). WSL is thus considered a subsystem of Windows rather than an independent Linux installation.

---

**(c)** Explain the difference between a **terminal (emulator)** and a **shell**, and give one example of each.

**Answer:**
A terminal is a medium by which you relay commands to your computer, and the shell interprets those commands. An example of a terminal is the Terminal app in macOS, and an example of a shell is zsh used in macOS.
